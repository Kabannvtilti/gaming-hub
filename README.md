# Gaming Hub

Навчальний лендинг української ігрової спільноти з форумом, Wiki та LFG. Лабораторна робота 9 — адаптивна форма зворотного зв’язку та клієнтська валідація.

Студент: Капущак Володимир, ПП-22.

## Перегляд

Відкрити папку у VS Code і запустити `index.html` через Live Server. Відео YouTube, Google Maps і Windy потребують доступу до Інтернету. Основні стилі, графіка і шрифти локальні.

## Структура

- `index.html` — сторінка лендингу.
- `assets/` — іконки, зображення і шрифти Arimo.
- `css/input.css` — вихідні стилі Tailwind.
- `css/tailwind.css` — готовий CSS, включений до репозиторію.
- `js/navigation.js` — мобільне меню та керування фокусом.
- `tailwind.config.cjs`, `package.json`, `pnpm-lock.yaml` — налаштування збірки.
- `.gitignore` — виключення залежностей, логів і локальних налаштувань.
- `.nojekyll` — вимкнення обробки Jekyll на GitHub Pages.
- `netlify.toml` — публікація кореня проєкту на Netlify.

## Збірка стилів

```sh
pnpm install --frozen-lockfile
pnpm run build
```

Для перегляду готової сторінки повторна збірка не потрібна.

## GitHub Pages

Після push до GitHub відкрити Settings → Pages → Deploy from a branch, вибрати `main` і `/(root)`. Дочекатися завершення публікації. Відносні посилання на ресурси підтримують розміщення у підкаталозі репозиторію.

## Netlify

У Netlify імпортувати GitHub-репозиторій. Publish directory — `.`, команда збірки порожня, оскільки CSS уже зібрано. Також можна завантажити окремий ZIP із файлами сайту вручну. Наявна адреса з попередньої роботи: https://gaming-hub-lab6-kapushchak.netlify.app/.

## Форма зворотного зв’язку

Секція `#feedback` містить ім’я, email, український телефон, повідомлення та обов’язкову згоду. Перевірка виконується у браузері; дані не передаються на сервер і не зберігаються. Успішне завершення очищує поля та відкриває демонстраційний діалог.

Телефон перевіряється строго як `+380` і 9 цифр. Для локального номера пропонується явне перетворення окремою кнопкою. Пробіли, літери й зайві цифри не обрізаються непомітно.

Правила винесено в `js/validation-rules.js`, роботу з DOM — у `js/validation.js`. Сторінку слід запускати через HTTP-сервер або Live Server, оскільки використовуються JavaScript-модулі.

```sh
node --test tests/validation.test.mjs
```

Тестовий набір містить 49 перевірок правил. Окремо виконано браузерні перевірки станів, клавіатури, повторного Submit та адаптивності. Правила й результати аудиту: `docs/Lab9_design.md`, `docs/Lab9_audit.md`.

## Vercel

Імпортувати репозиторій як Framework Other, корінь `./`. `vercel.json` задає порожню команду збірки й публікацію готових статичних файлів. Автоматичні деплої використовують гілку `main`.
