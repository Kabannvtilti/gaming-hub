## Промпт-паспорт

1. «На основі Lighthouse Mobile для Gaming Hub і мережевого звіту визнач, що затримує перший екран. Запропонуй мінімальні зміни JavaScript і responsive WebP із збереженням якості та функцій Fancybox».
2. «Проаналізуй зауваження target-size для Swiper. Збережи маленькі видимі точки, зроби клікабельні зони 24×24, перевір видимий фокус і вміщення на 320 px».
3. «Перевір lang, заголовки, alt, labels, фокус, контраст і зовнішні посилання. Додай покращення SEO лише там, де вони потрібні. Відклади сторонні iframe до дії користувача та збережи прямі посилання».
4. «Повтори Lighthouse із тими ж налаштуваннями й перевір регресії калькулятора, форми, меню, Swiper і Fancybox. Збери GitHub Actions для окремої гілки з перевіркою Tailwind, тестами та Vercel CLI після успішного CI».

## CI/CD

Workflow `.github/workflows/deploy.yml` запускається від push у гілку ЛР №12. Прямий деплой після тестів використовує секрет `VERCEL_TOKEN` і змінні `LAB12_VERCEL_ORG_ID` та `LAB12_VERCEL_PROJECT_ID` окремого проєкту ЛР №12. За відсутності конфігурації GitHub перевіряє збірку й тести та явно повідомляє, що прямий деплой пропущено. Не використовувати ідентифікатор проєкту ЛР №11.
