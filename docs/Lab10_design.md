# Gaming Hub Лабораторна 10

Новий блок `#community-media` доповнює лендинг навчальними відгуками та галереєю існуючих графічних активів. Вигадані відгуки явно позначені як демонстраційні.

## Прототип

https://stackblitz.com/edit/stackblitz-starters-fmbsjx5p?file=index.html

Прототип створено й збережено в Static HTML/JS/CSS StackBlitz, код підготовлено за допомогою ChatGPT. Перевірено Web Preview, стрілку слайдера, відкриття та гортання галереї. Збережену HTML-версію включено до `prototype/index.html`. Після перенесення до лендингу стилі та ініціалізацію винесено в `css/media.css` і `js/media.js`.

## Компоненти

- Swiper 11.2.10: шість слайдів, loop, autoplay із затримкою 3500 мс, pauseOnMouseEnter, стрілки, клікабельна пагінація, 1/2/3 слайди від 320/768/1024 px.
- Fancybox 5.0.36: п’ять активів у `gaming-gallery`, підписи, fade, зум до 3, стрілки, Escape, керування з клавіатури.
- Typed.js 2.0.12: три короткі фрази в Hero, typeSpeed 50, backSpeed 30, backDelay 1800, loop.

Версії CDN зафіксовано повністю. CSS підключено в head; бібліотеки та власний JS — перед body. Ініціалізація виконується після DOMContentLoaded, jQuery не потрібен.

## Доступність та відмови

Кнопка анімації зупиняє слайдер і друк. Фокус усередині слайдера призупиняє autoplay. Прихована вкладка зупиняє обидві анімації. prefers-reduced-motion вимикає автоматичний рух. Статичний текст для скринрідера не повторює кожну надруковану літеру.

Якщо CDN недоступний, відгуки лишаються картками, зображення — посиланнями, Hero — статичним текстом. Перевірки бібліотек незалежні: відмова однієї не блокує решту та форму ЛР9.

## Перевірка

`npm test` запускає 60 тестів: 49 правил форми й 11 контрактних перевірок керування медіакомпонентами. Контрактні тести перевіряють власний код на підставних адаптерах бібліотек; інтеграцію справжніх CDN перевірено окремо в браузері.

Перевірено ширини 320, 375, 768 і 1280 px, кнопки, пагінацію, цикл, реальне автопрогортання, зум, галерею та консоль. Початкові темні SVG погано читалися на темному фоні; у картках додано світлий фільтр, у Fancybox — світле тло SVG.

## Git та публікація

Для цієї роботи використано тільки `feat/lab10-media`. Існуючий репозиторій повторно перевірено через `git init`; його попередня історія збережена. Основна гілка не використовується для push ЛР10.
